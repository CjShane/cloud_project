# UI Component Skill

- Use Tailwind CSS
- Use functional React components
- Keep components small and reusable
- Use consistent spacing (p-4, gap-4, etc.)
- Use semantic HTML (section, nav, main)
- Ensure mobile responsiveness
- Prefer composition over complex monolithic components
- Provide loading, error, and empty states for data-driven UI
- Keep props typed and minimal
- Keep accessibility baseline: keyboard focus, labels, and contrast
